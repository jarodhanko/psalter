## Coverage and held scope

Regression tests compare all source events and part selections to independent printed ledgers, exercise stanza/learner/transposition preparation, real playback callbacks, selected-part muting and frozen tracking, and check exact source guards and saved print selection. Representative actual React screen/print calls use the real ABCJS renderer with synthetic jsdom bounds; these are preparation/notation checks, not native geometry approval. Build and exact budgets remain separate release gates.

Deferred issues remain deferred: #96 reduced-part fermata glyph ownership; #99 Alto half-rest visibility in explicitly empty-stanza print; #91 PENTECOST ambiguous selected-stanza print. The existing #99 carrier intentionally keeps score-follow tracking unavailable; this batch preserves that veto. No new presentation witness is introduced. Alto q75, RFPA middle slurs, #46b and unrelated optimization are untouched. Native browser acceptance, acoustic listening and OS/physical printing are not certified by these regressions.
